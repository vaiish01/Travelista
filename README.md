# Travalista – Travel Website

Travalista is a travel website developed as part of my MERN Stack internship. The application is designed to provide users with an engaging platform to explore travel destinations and discover travel experiences through a user-friendly interface.

The project demonstrates the implementation of a full-stack web application using the MERN (MongoDB, Express.js, React.js, and Node.js) technology stack.

## Features

- **Explore Destinations:** Browse and discover different travel destinations.
- **Responsive User Interface:** User-friendly interface designed for a smooth browsing experience.
- **Destination Information:** View details about travel destinations.
- **Dynamic Web Pages:** Interactive frontend developed using React.js.
- **Full-Stack Architecture:** Integration of frontend and backend technologies.

## Installation and Setup

### Prerequisites

Make sure the following are installed:

- Node.js
- npm
- MongoDB
- Git

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

Navigate to the project directory:

```bash
cd Travalista
```

### 2. Set Up the Frontend

```bash
cd client
npm install
npm run dev
```

### 3. Set Up the Backend

Open another terminal:

```bash
cd server
npm install
```

Create a `.env` file inside the server directory:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

Start the backend server:

```bash
npm start
```

> The commands may differ depending on the scripts defined in your `package.json` files.
